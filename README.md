# workProxy

按网络与地点规则自动开关 macOS 系统代理的菜单栏工具。完整需求见 [已确认规格](docs/spec-draft.md)。

当前实现不操作 Clash Verge / FlClash 的界面，也不使用辅助功能权限：规则命中后直接读写 macOS 系统代理。**TUN 不在控制范围**。

## 功能

- 菜单栏常驻；设置窗口使用 macOS 原生侧边栏布局，分为概览、规则、设置、关于。
- 概览页显示当前网络、系统代理实际状态、端点可达性、最近一次决策和规则数量。
- 规则编辑器使用分组表单与底部取消/保存，字段不完整时就地提示。
- 规则条件：Wi-Fi 名称，或指定有线接口。Wi-Fi 名称从系统保存过的网络列表中选择（当前连接优先），也可以手动输入未保存的网络。
- 地点是附加条件：地址搜索选点、设置半径；地点本身不触发规则。
- 规则可排序，从上到下取第一条匹配；地点规则新增时默认插在同网络普通规则之前。
- 新网络稳定 3 秒后才执行；短暂断线回到同一网络不执行；断线达到 3 秒后重连重新匹配。
- 未匹配保持现状且不提示；手动修改代理不会被持续纠正。
- 可能命中地点规则时最多等待定位 5 秒；定位不可用则跳过地点规则继续匹配；迟到的定位结果不补执行。
- 启动时应用一次；同网络唤醒不重复执行，异网络唤醒执行。
- 暂停不改变代理；恢复时立即应用当前规则。
- 默认登录启动（应用位于 `/Applications` 时自动注册），可关闭。
- 失败通知一次并在菜单栏显示，不无限重试。
- 开启系统代理前先探测端点 TCP 可连接；不可连接时拒绝写入，避免断网。

设置保存在 `~/Library/Application Support/workProxy/settings.json`。配置文件损坏时会改名隔离并回到默认设置。

## 构建与运行

需要 macOS 13+、Swift 6+ 和 Xcode/命令行开发工具；没有第三方依赖。

```sh
./scripts/build-app.sh
open dist/workProxy.app
```

应用图标由脚本生成，需要改图标时运行：

```sh
swift scripts/make-app-icon.swift Resources/AppIcon.icns
```

生成的应用使用本机临时签名，未公证。最低部署版本 macOS 13，当前只在 macOS 27.3 / Apple Silicon 构建与启动。

## 使用流程

1. 启动应用，点击菜单栏图标 →“打开设置”。
2. 首次使用点击“允许定位”，用于读取 Wi-Fi 名称和地点判断；不允许时 Wi-Fi 名称规则不会命中，有线规则仍可用。
3. 点击“添加规则”，从下拉框选择 Wi-Fi（或点“手动输入”填写未保存的网络），或选择有线接口；再选动作（开启/关闭系统代理），可选设置地点与半径。
4. 连接目标网络，等待 3 秒稳定后规则自动执行；状态显示在设置窗口顶部和菜单栏。
5. 需要临时停用时打开“暂停自动切换”；恢复时会立即按当前网络应用一次。

## 权限

- **定位**：读取 Wi-Fi SSID（macOS 要求）和地点判断；拒绝后 Wi-Fi 名称规则跳过。
- **通知**：仅在失败时发送一次；未授权时只在设置窗口和菜单栏显示错误。
- **登录项**：通过 `SMAppService` 注册；只在应用位于 `/Applications` 或 `~/Applications` 时自动注册。

## 命令行

```sh
# 只读：主接口、活动服务、每个服务的系统代理开关
dist/workProxy.app/Contents/MacOS/WorkProxy --status

# 对所有已启用的网络服务开启/关闭系统代理（不经过规则引擎）
dist/workProxy.app/Contents/MacOS/WorkProxy --on --endpoint 127.0.0.1:7897
dist/workProxy.app/Contents/MacOS/WorkProxy --off

# 只读：列出当前 Wi-Fi 与系统保存过的 Wi-Fi 名称
dist/workProxy.app/Contents/MacOS/WorkProxy --wifi-networks
```

`--on` 会先做一次 TCP 连接检查；端点不可连接时拒绝写入，退出码 1。

## 已知限制

- **TUN 不受控制**。TUN 开启时，关闭系统代理不等于流量直连。
- **客户端可能覆盖**。Clash Verge / FlClash 启动或重载时可能按自身配置重新应用系统代理；代理守护也会持续纠正。本工具不修改客户端设置。
- **端点必须可连接**。客户端内核未监听时不会开启系统代理。
- **PAC 与自动发现只读**。遇到 PAC 开启时，“全关”会显示为混合状态，工具不修改 PAC。
- **只作用于当前 Location**。工具写入当前网络位置中的服务，不修改服务顺序、DNS 或 Location。
- **需要管理员账户**。本机当前会话实测无需密码，但登录后的首次授权行为仍需验证。
- **IPv6 与双栈路径未单独验证**；主要连接按系统 IPv4 主接口判定。
- TUN/utun 被排除在网络身份之外；主接口判定为启发式，尚未完成真实 TUN 场景验证。
- 未签名开发包，未公证。
