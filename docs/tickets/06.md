# 06: 完善暂停、登录启动与睡眠唤醒

状态：拆分草稿，待用户确认后发布。

## Parent

https://github.com/sawyerfeng/workProxy/issues/1

## What to build

用户可让工具日常常驻，并通过暂停、恢复及登录启动设置控制自动化。

## Acceptance criteria

- [ ] 菜单栏和设置窗口展示自动化状态；暂停不改变代理并取消未完成的待执行任务。
- [ ] 恢复时立即开始当前规则匹配，沿用必要的稳定判断及最多 5 秒定位等待，避免重复执行。
- [ ] 应用启动时匹配当前规则一次；同网络唤醒不执行，异网络唤醒才执行。
- [ ] 默认请求启用登录启动且可关闭；展示系统实际状态，系统拒绝或用户禁用不能显示已成功。
- [ ] 失败状态与单次通知在后台可用，通知权限拒绝仍在菜单栏显示结果，不持续重试。
- [ ] 验证启动、暂停、恢复、睡眠及切网并发时，旧任务不会覆盖新状态。
