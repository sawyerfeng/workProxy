# 02: 验证两款客户端的端点与运行状态

状态：拆分草稿，已按 2026-11-11 范围决定修订，待用户确认后发布。

## Parent

https://github.com/sawyerfeng/workProxy/issues/1

## What to build

让系统代理端点可配置并持久化，验证 Clash Verge 与 FlClash 在运行、未运行、退出和重载时与外部系统代理写入的相互关系。仍然不操作客户端界面。

## Acceptance criteria

- [ ] 设置中可配置代理端点，默认 `127.0.0.1:7897`，重启后保留；非法格式明确拒绝。
- [ ] 分别验证两款客户端：内核端口监听时可开启，未监听时拒绝且不修改系统代理。
- [ ] 观察客户端启动、退出、重载是否覆盖外部写入的系统代理；记录实际结果，不假设行为一致。
- [ ] 如客户端会覆盖，给出明确使用条件（例如关闭代理守护、保持客户端运行）或在文档中列为已知限制。
- [ ] 不自动启动客户端，不读取订阅、密钥或精确私人位置。
- [ ] 保存两款客户端的真实验证证据；未完成的一项不能被写成“已兼容”。
