# 05: 为网络规则加入地址搜索与地点范围

状态：拆分草稿，待用户确认后发布。

## Parent

https://github.com/sawyerfeng/workProxy/issues/1

## What to build

用户搜索地址、选择中心点和半径，为网络规则附加地点条件，仅在既定触发时判定。

## Acceptance criteria

- [ ] 支持地址搜索、结果选择、正数半径配置、修改和持久化；地点条件可用于既有通用网络规则。
- [ ] 新增地点规则默认排在同网络普通规则前；网络与地点条件同时满足才命中。
- [ ] 只有可能命中的地点规则需要定位；单次匹配最多等 5 秒，失败跳过地点规则继续查找。
- [ ] 检查位置时间与精度，记录采用阈值及理由；过旧、无效、精度不足无法区分边界时按不可用处理。
- [ ] 位置变化本身、迟到结果不触发；等待中切网取消旧任务。
- [ ] 地址搜索失败可见且可重试；未知网络及未匹配仍保持状态不提示，不自动撤销上次动作。
- [ ] 验证圈内、圈外、边界不确定、超时及权限拒绝的整条匹配行为。
