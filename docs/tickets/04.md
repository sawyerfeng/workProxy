# 04: 支持有线规则与双连接优先级

状态：拆分草稿，待用户确认后发布。

## Parent

https://github.com/sawyerfeng/workProxy/issues/1

## What to build

用户选择有线接口建立规则，Wi-Fi 与有线并存时跟随主要物理连接执行。

## Acceptance criteria

- [ ] 设置中可选择有线接口并保存规则，接口身份与用户可读名称分开处理。
- [ ] 验证 Wi-Fi 到有线、有线到 Wi-Fi、网线拔插及双连接优先级变化，复用防抖与规则顺序。
- [ ] TUN 开关不被误判为物理网络切换；覆盖 IPv4/IPv6 路径差异并记录确定的主要连接判定方法。
- [ ] SSID/定位不可用时，可识别且无需定位的有线规则仍可匹配。
- [ ] 所选接口消失或网络服务重建时明确展示不可用，不能错误绑定其他接口。
