# 07: 交付可安装第一版并验证完整使用流程

状态：拆分草稿，待用户确认后发布。

## Parent

https://github.com/sawyerfeng/workProxy/issues/1

## What to build

交付从首次安装授权到按网络和地点自动切换的完整 macOS 应用，附可复现的兼容性结果。

## Acceptance criteria

- [ ] 产出可安装的应用包、构建与安装说明，明确支持的 macOS 与 CPU 架构；如缺少签名凭据，明确标识未签名开发包，不宣称已公证。
- [ ] 首次启动可完成必要授权（如定位）、创建与排序规则，退出重开后保留配置。
- [ ] 在 Clash Verge 与 FlClash 分别运行的情况下完成 Wi-Fi、有线、双连接、地点匹配、定位降级、暂停恢复和唤醒矩阵。
- [ ] 真实验证系统代理实际状态与规则目标一致；外部写入可能不反映在客户端界面，需在文档中说明；TUN 不产生反馈循环，手动调整不会被持续覆盖。
- [ ] 用户可理解权限、端点不可连接、客户端未运行和部分失败状态，未知网络保持安静。
- [ ] 发布兼容性及未解决限制清单；未通过的核心控制能力不能被包装成可用第一版。
