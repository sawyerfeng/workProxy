# 03: 按 Wi-Fi 名称规则自动切换代理

状态：拆分草稿，待用户确认后发布。

## Parent

https://github.com/sawyerfeng/workProxy/issues/1

## What to build

用户在设置窗口维护 Wi-Fi 规则，切换网络后稳定等待再应用第一条匹配规则，保留手动操作。

## Acceptance criteria

- [ ] 支持 Wi-Fi 名称、开/关系统代理两种动作的规则新增、编辑、删除、拖动排序与持久化；从上到下只执行第一条匹配。
- [ ] 新连接稳定 3 秒才执行；短于 3 秒断线后回到同一网络不执行，断线达到 3 秒后重连需重新匹配。
- [ ] 无匹配保持原状态且不提示；用户手动修改后不持续纠正。
- [ ] 读取 SSID 所需授权有引导，拒绝或撤销权限不会将未知 SSID 误判为空名称规则。
- [ ] 比较物理网络身份，系统代理写入、DNS 与客户端 TUN 引起的路由变化不重复触发；连续切网取消过期执行。
- [ ] 以网络事件到代理动作的高层测试验证排序、时序、手动优先与失败通知；补充真实 Wi-Fi 切换证据。
