## What to build

通过菜单栏工具和验证窗口，直接读写 macOS 系统代理，完全不操作 Clash Verge / FlClash 的界面，不使用辅助功能权限。

## Acceptance criteria

- [ ] 提供可运行的 macOS 应用、菜单栏入口、验证窗口和只读状态命令，记录构建方式与测试系统版本。
- [ ] 对当前 Location 中所有已启用的网络服务统一开启或关闭 HTTP、HTTPS、SOCKS 代理；重复设置同一状态不产生反向切换。
- [ ] 开启时显式写入端点地址与端口，并回读每个服务的三个开关；只凭命令退出码不算成功。
- [ ] 开启前探测端点 TCP 可连接；不可连接时拒绝写入并说明原因。
- [ ] PAC 与自动发现只读取并报告，不修改；遇到 PAC 开启导致无法判定“全关”时明确显示混合状态。
- [ ] 实际操作前记录初态，完成后可恢复；部分失败显示实际状态，不自动重试。
- [ ] 至少完成一次真实开启与一次真实关闭，记录前后系统代理与主接口；测试结束恢复初态。
- [ ] 文档明确 TUN 不受本工具控制，TUN 开启时关闭系统代理不等于流量直连。
