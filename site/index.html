01切网先关，连稳再判断网或切换网络时先立即关闭代理，等新网络连稳后再按规则决定是否开启；连上陌生网络默认保持关闭，避免带着旧代理打不开网页。

02按序匹配，首条生效上下拖动即可调整优先级，把带地点的细分规则排在前面。每次只执行第一条命中的规则，逻辑直观、结果可预期。

03不抢控制，不乱重试同网络唤醒不会重复触发，暂停期间也不改动当前代理；遇到客户端未启动或切换失败时只提醒一次，不在后台反复重试。

下载前，
你可能想了解这些。

旧版 0.1.0 怎么升级？之后如何更新？

如果你还在用 0.1.0，请先手动下载安装一次最新版 DMG（拖入“应用程序”覆盖旧版）。从 0.2.0 起已内置自动更新功能，后续可直接在应用内检查、下载并完成安装，也可在设置中关闭自动检查。查看更新说明 ↗

Clash 联动里的“控制器地址”应该填哪个？

请填写客户端开放的本机 HTTP 外部控制器地址（例如 http://127.0.0.1:9090），不要填成代理流量端口（如 7897）或带 /ui 的网页面板地址。查看 FlClash / Clash Verge Rev 配置指南 ↗

它能代替 Clash 或其他代理软件吗？

不能。workProxy 本身不提供节点、订阅或代理服务，它只负责按规则帮你自动开关代理，需要配合 Clash、FlClash、Clash Verge Rev 等已有客户端一起使用。

支持哪些 Mac 和系统版本？

目前提供的 DMG 安装包支持搭载 Apple 芯片（M 系列）的 Mac，系统要求 macOS 13 及以上。Intel 机型可以拉取源码自行编译，但暂未经过真机测试。

首次打开提示“无法验证开发者”怎么办？

应用目前使用本地临时签名打包，暂未经过 Apple 公证，首次打开可能会被系统安全检查拦截。确认安装包来自官方 GitHub Releases 后，可在“系统设置 → 隐私与安全性”中手动允许运行，也可以直接下载源码自行构建。

支持和 FlClash、Clash Verge Rev 联动吗？

只要客户端开启了本机 Mihomo HTTP 外部控制器，填好地址和密钥即可联动（目前已在 FlClash 上实测，Clash Verge Rev 尚未完整验证）。建议同时关掉客户端自带的“系统代理守护”，避免两边互相覆盖。另外，系统代理和 TUN 是分步切换的，若客户端重启重载或某一步未生效，界面都会明确提示。

规则和密钥保存在哪里？会上传隐私数据吗？

所有规则、地点坐标和控制器密钥都只保存在本机的 ~/Library/Application Support/workProxy/settings.json 中（仅当前用户可读写）。密钥目前以明文存储，暂未接入系统钥匙串，反馈问题时请不要上传该文件。除搜索地址、展示地图（调用 Apple 系统服务）和检查更新外，应用不会联网发送任何数据。
