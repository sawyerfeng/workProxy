下载之前，
你可能想知道。

0.1.0 如何升级？以后怎么更新？

0.1.0 需先手动安装一次 0.2.0。之后可在应用内检查、下载并安装更新，也可以在设置中关闭自动检查。查看更新说明 ↗

Clash 控制台地址应该填哪个？

填写客户端的本机 HTTP 控制器地址，例如 http://127.0.0.1:9090，不能填写代理端口或网页面板地址。查看 FlClash / Clash Verge Rev 配置指南 ↗

它能代替 Clash 或 VPN 吗？

不能。workProxy 是开关与规则工具，需要配合已有代理客户端使用，不提供节点、订阅或代理服务器。

支持哪些 Mac？

当前 DMG 面向 Apple Silicon（M 系列），部署目标为 macOS 13+。Intel 可尝试源码构建，但尚未实机验证。最低系统版本、首次授权及真实 TUN 网络切换仍需更多实测。

为什么会提示无法验证开发者？

当前版本使用本机临时签名，没有 Developer ID 签名和 Apple 公证，首次打开可能被 macOS 拦截。请阅读发布说明，确认下载来源后再决定是否安装。

FlClash 和 Clash Verge Rev 都能联动吗？

使用通用 Mihomo HTTP API。需在客户端启用本机控制器，并填写正确密钥。Clash Verge Rev 尚未实机验证；客户端重启或重载可能覆盖运行状态，workProxy 不持续守护。系统代理与 TUN 的修改也不是原子操作。

规则和密钥保存在哪里？

保存在本机的 ~/Library/Application Support/workProxy/settings.json。密钥以明文存储，不使用钥匙串，请勿分享该文件。地址搜索和地图使用 Apple 系统服务，需要联网。
